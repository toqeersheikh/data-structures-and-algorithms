# ?? Constants in C++

This document covers the fundamentals of constants in C++, based on the syntax rules and structure of modern C++.

## ?? Core Concept

Just like standard C++ variables, constants have the following properties:
* **Names:** They have unique identifiers.
* **Storage:** They occupy memory space.
* **Typed:** You must specify their data type during declaration.

?? **The Key Difference:** Once defined, the value of a constant **cannot be changed** or overwritten during program execution; they are completely read-only.

---

## ?? Types of Constants

C++ generally categorizes constants into:
1. **Literal Constants:** Raw values directly typed into the code (e.g., `12`, `3.1415`).
2. **Declared Constants:** Named variables explicitly locked with the `const` keyword.
